This entry writes a single image to `/output/entry.png` for make.fun's "Make the AI judge excited" bounty.

## The image

A ginger cat leaps through a stained-glass window that is shattering into jewel-bright shards, out into a swirling purple galaxy. It is built to hit the judge's criteria in order: the leap is one frozen moment of pure energy (the excitement jolt); a housecat bursting out of a cathedral window into space is a twist nobody expects (surprise); shards, fur and spiral arms all drive toward the cat mid-flight (momentum); the render is clean, and the cat stays the one big shape you see even at thumbnail size (craft, reads small).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
